# Русские поместья — три концепции первых двух экранов

Опубликованный предпросмотр: https://kastet36.github.io/ruspom-landing/

- `index.html` — сравнение трёх концепций.
- `variants/01.html` — архитектурный журнал: светлая композиция, крупная типографика, горизонтальная галерея.
- `variants/02.html` — тепло своего дома: тёплая палитра, антиква, свободная фотокомпозиция.
- `variants/03.html` — современный производитель: контраст, ясная геометрия, строгая галерея работ.
- `research.html` — ориентиры и принципы оформления.
- `content.json` — дословные тексты первого экрана.
- `assets/concepts.css` и `assets/concepts.js` — оформление и взаимодействия.
- `assets/photos/` — 14 оптимизированных фотографий из папки пользователя.
- `assets/logo-official.png` — официальный логотип, скопирован без изменений из `Логотип/лого_1.png`.

## Тексты и материалы

Заголовок, описание, текст основной кнопки и два факта о компании дословно сохранены из файла «Структура с текстами». Оформление разделяет исходный абзац на читаемые блоки, не меняя формулировки. Второй экран имеет исходный заголовок «Построенные нами каркасные дома». Подписи описывают только видимые детали фотографий, без вымышленных названий проектов, площадей и цен.

Геометрия домов, отделка, окружение и водяные знаки на фотографиях сохранены. Выполнены только уменьшение разрешения и сжатие в WebP. Использованы реальные фотографии, генеративной ретуши в этой версии нет. Оригиналы находятся в `/root/Русские поместья/Фото/`.

Форм и плееров нет. Кнопка каталога демонстрирует своё расположение и показывает примечание о согласовании. Фотографии галереи можно открыть крупнее; первый вариант имеет прокручиваемую галерею с кнопками. Окно фотографии закрывается кнопкой, клавишей Escape или нажатием за его пределами. Телефон ведёт на `tel:`.

## Публикация

GitHub Pages настроен на ветку `main`, папку `/ (root)`. Каждый push автоматически публикует изменения. `.nojekyll` отключает обработку Jekyll. Сервер и собственный домен для этого предпросмотра не используются.

## Локальный просмотр

```sh
python3 -m http.server 8080
```

Открыть http://localhost:8080/.

## Проверка

Перед публикацией проверяются три варианта на компьютере и телефоне: дословное совпадение первого экрана с `content.json`, наличие двух секций и реальных фотографий, официальный логотип, загрузка локальных файлов, отсутствие горизонтальной прокрутки и форм, переключение вариантов, галерея, открытие и закрытие фотографий.

Старые иллюстрации и исследовательские скриншоты в `research/` являются историей предварительной версии и на новых концепциях не используются.
