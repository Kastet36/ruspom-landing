# Русские поместья — первые экраны и ипотека

Предпросмотр: https://kastet36.github.io/ruspom-landing

Основное направление — утверждённый пользователем **01 «Кинематограф»**. См. [CONCEPT.md](CONCEPT.md).

## Реализовано

1. Первый экран из утверждённого HTML: исходные фон, логотип, типографика, цвета, текст и кнопка. Убран переключатель трёх концепций.
2. Галерея из всех 13 актуальных фотографий пользователя. Формат снимков 4:3 сохранён, подписи описывают только видимые детали.
3. Компактный блок семейной ипотеки от 6% годовых, эскроу и аккредитации в банках. Кнопка «Узнать условия» ведёт на телефон компании.

На телефоне обе галереи листаются пальцем: в блоке страницы и в полноэкранном просмотре. На компьютере доступны видимые стрелки и перетаскивание мышью. В открытом просмотре также работают миниатюры, счётчик, клавиши стрелок, Home/End и закрытие по Escape. После закрытия восстанавливаются положение страницы и фокус на выбранной фотографии.

Формы и отправка заявок не подключены. Кнопка каталога показывает примечание о текущем этапе согласования. Пункты навигации будущих разделов также помечены пояснением при нажатии. Контактный телефон работает через `tel:`.

## Файлы

- `index.html` — первый экран и галерея.
- `assets/cinema.css`, `assets/cinema.js` — оформление и поведение.
- `assets/cinema/hero-approved.jpg`, `logo-approved.png` — изображения, извлечённые без перекодирования из утверждённого пользователем HTML.
- `assets/cinema/preview-*.webp` — лёгкие превью 960×720 для галереи на странице.
- `assets/cinema/house-*.webp` — текущие фотографии из папки «Фото», уменьшенные максимум до 1920×1440 и сжатые для загрузки.
- `assets/cinema/thumb-*.webp` — миниатюры для открытого просмотра.
- `provided/rp_checked_a_1440.png` — контрольный скриншот выбранной концепции из архива пользователя.
- `research/verification-cinema.json` — результаты браузерной проверки.

Снимки не ретушировались: геометрия, материалы, окружение и водяные знаки сохранены. Фото 4 отсутствует в текущей папке пользователя и в новую галерею не включено.
