# Три направления после пересмотра композиции

Первые два раздела в каждом варианте: предложение и построенные дома. Тексты первого экрана дословно из content.json, фотографии и логотип предоставлены пользователем.

1. Погружение — полноэкранная фотография с текстом поверх, затем одна большая работа с переключаемыми миниатюрами. Ориентиры: Vipp Guesthouses, August Antwerp, панорамная подача Four Seasons из Lazyweb.
2. Архитектурный альбом — центральный заголовок, вертикальная фотография, небольшой снимок террасы и текстовая колонка; второй экран как журнальный разворот. Ориентир: редакционный подход Norm Architects.
3. Точный подход — контрастный типографический блок с фактами, модульная сетка условий и фотографий; второй экран как архив со списком работ и большим выбранным изображением. Ориентиры: модульность USM и графика Snøhetta.

Lazyweb использован до изменения UI. Сессия: https://www.lazyweb.com/agentic-search/2c7b5c03-4731-4008-be36-44c1ac3aad57
Выбранный пример панорамной подачи: screens:56f4143ac9d6c520c08377a8 (Four Seasons). Дополнительный найденный пример архитектурного архива: screens:73c8febfe96d59f7f880476a (ALT Studios).
