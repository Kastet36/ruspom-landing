# Русские поместья — варианты из архива пользователя

Предпросмотр: https://kastet36.github.io/ruspom-landing/

Главная страница `index.html` побайтово совпадает с `russkie_pomestya_three_final_concepts.html` из предоставленного архива `russkie_pomestya_concepts.zip`. Дизайн, тексты, встроенные изображения и переключатель трёх вариантов сохранены без изменений.

Варианты переключаются кнопками вверху страницы:

1. Кинематограф.
2. Архитектура.
3. Современный.

Исходные скриншоты из того же архива:

- [Кинематограф](provided/rp_checked_a_1440.png)
- [Архитектура](provided/rp_checked_b_1440.png)
- [Современный](provided/rp_checked_c_1440.png)

HTML автономный: изображения встроены, внешних загрузок нет. В исходнике есть демонстрационное окно каталога; введённые данные никуда не отправляются. Второй блок представлен заголовком и текстовой заглушкой, как в предоставленном файле.

Предыдущие разработки сохранены в `variants/` и истории Git, на главной странице теперь материалы пользователя.

## Публикация

GitHub Pages публикует ветку `main`, папку `/ (root)`. Каждый push автоматически обновляет предпросмотр.
