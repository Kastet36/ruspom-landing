# Русские поместья — три концепции первого экрана

Только визуальное согласование. Во всех трёх вариантах одинаковый текст из исходного файла. Форм нет. Старая версия полного лендинга в этот репозиторий не включена.

- `index.html` — обзор трёх концепций.
- `variants/01.html` — светлая композиция с фото справа. Рекомендуемый вариант.
- `variants/02.html` — фото на весь экран и контрастный текст.
- `variants/03.html` — тёплая журнальная композиция и антиква.
- `research.html` — шесть российских и зарубежных примеров, выводы и рекомендация.
- `content.json` — дословные тексты первого экрана для сверки.
- `research/source-text.txt` — исходный файл со структурой.

## Просмотр

```sh
python3 -m http.server 8080
```

Затем открыть http://localhost:8080.

## GitHub Pages

Публикация настроена из ветки `main`, папка `/ (root)`. Статические страницы находятся в корне репозитория, `.nojekyll` отключает обработку Jekyll. Каждый push в `main` автоматически обновляет опубликованные концепции через стандартную публикацию GitHub Pages. Дополнительный workflow не нужен.

Адрес: https://kastet36.github.io/ruspom-landing/ .

[Официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Материалы

На рабочем сервере фотографии можно положить в `/root/Русские поместья/Фото/`, официальный логотип — в `/root/Русские поместья/Логотип/`. Можно также прикрепить файлы прямо к чату. Мы подключим их после загрузки, не меняя тексты.

В макетах временная AI-визуализация дома; на страницах она явно отмечена и не выдаётся за построенный объект. Изображение одно и то же во всех концепциях: сравниваем оформление при одинаковом тексте и материале. Официальный логотип не удалось скачать с сайта компании. Поэтому на макетах обычное текстовое название, без вымышленного знака. Видео из ВК подключим после выбора концепции.

Кнопка каталога демонстрационная: нажатие показывает примечание, ничего не отправляет и не собирает данные. Контактный телефон ведёт на `tel:` по номеру из исходного файла.

## Проверка

Все варианты проверяются в Chromium на ширинах 360, 390, 768, 1280 и 1440 px: точное совпадение заголовка, описания, кнопки и двух фактов с `content.json`, отсутствие форм и плееров, отсутствие горизонтальной прокрутки, загрузка локальных изображений и шрифтов, переключение вариантов и уведомление кнопки.
