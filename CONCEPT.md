# Утверждённая концепция лендинга

Пользователь выбрал **01 «Кинематограф»** из своего архива `russkie_pomestya_concepts.zip` как основное направление для дальнейшей разработки всего лендинга.

## Источник

- Вариант A из исходного архива; в текущем `index.html` это секция `#home`.
- Контрольный скриншот: `provided/rp_checked_a_1440.png`.
- Исходный HTML в архиве: `russkie_pomestya_three_final_concepts.html`.

Выбран именно вариант из архива пользователя. Более ранние разработки в `variants/` и два других варианта архива не являются основой дальнейшей работы.

## Основа оформления

- Фотография дома на весь первый экран.
- Тёмный фон и затемнение под текстом.
- Тёплый свет на фотографии и золотистый акцент основной кнопки.
- Крупный заголовок без засечек, предложение слева, факты о компании внизу.
- Последующие разделы должны продолжать характер выбранного первого экрана.

## Действующие требования к продолжению

- Структуру и тексты брать из файла пользователя «Структура с текстами». Тексты первого экрана самостоятельно не переписывать.
- Для фотографий выполненных работ использовать материалы из папки «Фото».
- Использовать официальный логотип «Русские поместья».
- Видео будут из ВК; конкретные ролики предоставит пользователь.
- Сейчас согласовывается визуал. Рабочие формы и сбор заявок не подключать без дальнейшей задачи.
- Предпросмотр и обновления публиковать через GitHub Pages в `Kastet36/ruspom-landing`.

## Текущее состояние

Свёрстан полный лендинг: первый экран, фотогалерея, выбор проекта, комплектации и материалы, ипотека, порядок строительства, видеоотзывы, каталог и контакты.

Первый экран и все разделы объединены почти чёрным фоном `#0a0c0b`. Внизу главной фотографии — плавное затемнение до этого цвета.

Фотогалерея и видеоотзывы листаются стрелками, свайпами и перетаскиванием мышью. Счётчики и подсказки «Листайте» в блоках страницы убраны по просьбе пользователя.

Видеоотзывы пока представлены четырьмя явно обозначенными местами «Видео скоро». Пользователь передаст ролики из ВК позднее. Данные роликов находятся в `assets/cinema/videos.json`; плеер создаётся только при открытии карточки с указанным `embedUrl` и удаляется при закрытии.

Контакты свёрстаны без карты. Рабочие формы не подключены. Кнопки первого экрана и выбора проекта ведут к разделу каталога; финальная выдача каталога пока демонстрационная, как на предыдущем этапе согласования визуала.

Основные тексты взяты из файла «Структура с текстами». Пользователь разрешил переработать формулировки блока комплектаций при пересмотре композиции.

## Ипотечный блок

По просьбе пользователя добавлены семейная ипотека от 6% годовых, работа через эскроу-счёт и аккредитация в 5 банках. Текст короткий, без калькулятора и форм. Кнопка ведёт на телефон компании. Источники: `research/mortgage-sources.md`.

Постоянный адрес для пользователя: https://kastet36.github.io/ruspom-landing . Все обновления публикуются здесь; публичные ссылки давать без параметров версии.

## Пересмотр блока комплектаций

Выбран открытый сравнительный разворот: общая основа обеих комплектаций, затем тёплый контур и вариант с отделкой. Две большие карточки с обводкой убраны. Добавлены две условные изометрические схемы одного дома: оболочка и оболочка с внутренними работами и инженерией. Схемы поясняют степень готовности, не содержат размеров и не представляют реальный проект или рабочий чертёж.

Материалы показаны тремя общими фактами; исходные подробности раскрываются через «Подробнее о материалах». Формулировки этого блока сокращены по согласованному предложению. Первый экран и остальные разделы не менялись.
